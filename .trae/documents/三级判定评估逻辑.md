# LLM 裁判三级判定（verdict 0/1/2）设计文档

> 模块：知识抽取 · 质量评估（G-Eval 风格 LLM-as-Judge）
> 相关代码：`pybackend/api/evaluation.py`、`frontend/src/views/Extraction.vue`

## 一、背景与动机

原实现采用**二值判定**：裁判对每条样本输出 `pass: true/false`，指标得分 = 通过数 / 总数。

二值判定存在明显的信息损失——知识抽取中大量样本处于"接近正确但有轻微偏差"的灰色地带：

| 样本类型 | 示例                                 | 二值判定结果    | 问题        |
| ---- | ---------------------------------- | --------- | --------- |
| 完全正确 | 原文"张三获得国家自然科学奖"，抽取 `张三—获得→国家自然科学奖` | pass=true | 无         |
| 部分正确 | 同上原文，抽取 `张三—相关→国家自然科学奖`（方向对但谓词粒度粗） | 只能 false  | 与完全错误无法区分 |
| 完全错误 | 原文未提及，抽取 `李四—获得→国家自然科学奖`           | false     | 无         |

部分正确样本被一刀切为"未通过"，导致指标得分系统性偏低且无法定位改进方向（不知道是"全错"还是"差一点"）。

## 二、三级判定定义

| verdict | 含义                 | 典型场景                             |
| ------- | ------------------ | -------------------------------- |
| **2**   | 完全满足评估标准           | 三元组、谓词、实体边界、时间标注全部准确             |
| **1**   | 部分满足（存在轻微偏差，无事实错误） | 关系方向正确但谓词粒度宽泛；实体边界轻微不精确；时间区间部分吻合 |
| **0**   | 不满足评估标准或存在错误       | 事实错误、幻觉、证据不支持                    |

判定原则：**只允许基于原文判定，禁止使用裁判模型自身世界知识推断**（继承自 G-Eval 的 reference-free 约束）。

## 三、实现细节

### 3.1 Prompt 设计（`_judge` 函数）

```
输出要求（严格 JSON）：
{"items": [{"id": <样本id>, "verdict": 0或1或2, "reason": "<不超过40字的判定理由>"}],
 "summary": "<不超过80字的整体质量结论>"}

verdict 判定标准：2=完全满足评估标准；
1=部分满足（存在轻微偏差，如关系方向正确但谓词粒度宽泛、实体边界轻微不精确、
时间区间部分吻合等）；0=不满足评估标准或错误。
```

要点：

- 三级标准**显式写在 prompt 中**，并给出部分正确的具体示例，降低裁判主观摇摆

- `reason` 逐条强制输出，为前端失败样本下钻提供依据

- 每个指标（忠实度/谓词合理性/双时态/证据/实体边界）仍注入各自的 criteria，verdict 层级是所有指标共用的判定粒度

### 3.2 解析与防御性兼容

```python
try:
    verdict = int(v.get("verdict"))
    if verdict not in (0, 1, 2):        # LLM 输出越界（如 3、-1）
        verdict = 2 if v.get("pass") else 0
except (TypeError, ValueError):          # LLM 漏输 verdict 或输出非数字
    verdict = 2 if v.get("pass") else 0  # 回退旧版 pass 布尔
```

两重防御：

1. **越界值纠正**：verdict 不在 {0,1,2} 时按旧 pass 字段推断
2. **缺失/类型错误兜底**：异常时回退布尔推断；若 pass 也缺失，保守取 0

兼容性保证：历史评估记录（二值判定时期）回看时，`pass=true→verdict 2`、`pass=false→verdict 0`，明细展示与计分逻辑无需分支处理。

### 3.3 计分公式

```
指标得分 score = Σ verdict_i / (2 × n)     n = 样本总数
综合得分 overall = mean(选中且已出分指标的 score)   （等权）
```

每条样本满分 2 分，部分正确贡献 1 分（半分权重）。

**效果对比**（3 条样本：2 条完全正确 + 1 条部分正确）：

| 判定方式 | 计算            | 得分        |
| ---- | ------------- | --------- |
| 二值   | (1+1+0)/3     | 0.667     |
| 三级   | (2+2+1)/(2×3) | **0.833** |

部分正确的样本贡献了应有的部分分值，指标得分能反映"接近正确但有轻微偏差"的质量梯度。

### 3.4 前端展示

明细行三色标签（`detailVerdictType` / `detailVerdictText`）：

| verdict | 标签   | 颜色         |
| ------- | ---- | ---------- |
| 2       | 通过   | 绿（success） |
| 1       | 部分正确 | 黄（warning） |
| 0       | 未通过  | 红（danger）  |

每条样本可点击**下钻弹窗**：样本三元组 + verdict 标签 + 裁判理由（reason）+ 原文定位（head/tail/name/evidence 关键词高亮），便于人工复核"部分正确"到底差在哪。

## 四、与各评估指标的适配

三级判定对 5 个裁判指标统一生效，"部分正确"在各指标下的含义：

| 指标       | verdict=1 的典型形态                   |
| -------- | --------------------------------- |
| 三元组忠实度   | 头尾实体正确但关系在原文中仅为隐含/推断可得            |
| 谓词合理性    | 关系方向正确、无事实错误，但谓词粒度宽泛（如"相关"代替"获得"） |
| 双时态标注正确性 | 有效时间区间与原文部分吻合（起止其一准确）             |
| 证据句有效性   | 证据片段真实存在但只覆盖三元组的一部分               |
| 实体边界正确性  | 实体名可用但边界轻微不精确（多/少包含了一个修饰词）        |

## 五、边界情况

| 情况                           | 处理                                   |
| ---------------------------- | ------------------------------------ |
| 抽取结果无关系、只选了关系级指标             | 按缺失计 0 分（不走 LLM 调用），理由注明"实体孤立率 100%" |
| 证据句有效性遇到无证据片段的关系             | 该关系不进入样本（无 evidence 无法判定）            |
| LLM 漏判某条样本（verdicts 中无对应 id） | 该条保守取 0 分                            |
| 用户自定义选择指标子集                  | 只对选中指标执行判定与计分，overall 为选中指标均值        |

## 六、验证记录（2026-09 冒烟测试）

测试样本：`张三—相关→国家自然科学奖`（原文："他曾获得国家自然科学奖"）

- 裁判输出：`verdict=1`，理由"原文为获得奖项，'相关'过于宽泛"

- 该批 3 条样本得分：`(2+2+1)/6 = 0.8333`（二值判定下为 0.6667）

- 结论：三级判定成功区分了"谓词粒度粗"与"完全错误"，与设计预期一致
